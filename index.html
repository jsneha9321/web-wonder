How a project runs

Five stages, start to launch.

No jargon, no surprise invoices. You'll know exactly what stage the project is in at every point.

01

Discovery call

We talk through your business, audience, and what the site needs to achieve — then we scope the build and quote a fixed price.

02

Wireframe & content plan

A simple layout plan for every page, so we agree on structure and messaging before any visual design starts.

03

Design

A full visual design using your brand colors and logo, shared for feedback before a single line of code is written.

04

Build in WordPress

The approved design gets built out, tested across devices, and connected to any tools you need — forms, store, analytics.

05

Launch & handover

The site goes live, and you get a short walkthrough so you're confident editing content yourself afterward.
