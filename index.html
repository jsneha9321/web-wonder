How a project runs

Seven stages, start to launch.

No jargon, no surprise invoices. You'll know exactly what stage the project is in at every point.

01

Discovery call

We talk through your business, audience, and what the site needs to achieve.

02

Proposal & quote

A clear scope document and a fixed price — no surprise invoices once work starts.

03

UI design

A full visual design using your brand colors and logo, shared for feedback before any code is written.

04

Development

The approved design gets built out in WordPress and connected to any tools you need — forms, store, analytics.

05

Testing

Every page checked across devices and browsers — speed, forms, links, and mobile behaviour included.

06

Launch

The site goes live, with a short walkthrough so you're confident editing content yourself afterward.

07

Support

A window of post-launch support to fix anything that comes up once real visitors start using the site.
